# 用 Chrome 擴充功能找名單（給 Claude in Chrome／Cowork 讀）

> **使用者怎麼用**：Chrome 開著，打開 Claude 擴充功能，新對話貼上：
>
> 「照 https://github.com/a0955072107-bit/-/blob/main/sales/outreach/擴充功能找名單.md 找名單，今天找 Flushing 的餐廳 10 家。」
>
> （地區、行業、家數照當天要的改。）

## 規則
1. **只查資料，不送任何訊息、不留評論、不按讚、不填任何表單。**
2. 不登入任何帳號也能做；需要登入的頁面就跳過。
3. 只記錄店家公開的商業資料。不記錄員工或老闆個人的手機、私人 Email、私人社群帳號。

## 搜尋
在 Google 地圖搜尋「<行業英文> <地區>」，例如 `Chinese restaurant Flushing NY`、`Chinese dentist San Gabriel CA`、`Chinese tutoring Cupertino`、`Chinese hair salon Arcadia CA`。

**新行業（11/27 起）**，搜尋字可以這樣寫（`<city>` 換成下面的地區）：
- 會計報稅：`Chinese CPA <city>`、`Chinese accountant <city>`、`Chinese tax preparation <city>` → category 填 `accounting`
- 房地產：`Chinese realtor <city>`、`Chinese real estate agent <city>` → category 填 `realestate`
- 律師：`Chinese immigration lawyer <city>`、`Chinese lawyer <city>`、`Chinese family lawyer <city>` → category 填 `law`
- 保險：`Chinese insurance agent <city>`、`Chinese insurance agency <city>` → category 填 `insurance`

律師和保險的網站常常不能寫保證結果（律師廣告規範、保險廣告規範），所以 notes 只寫主要服務（例如「移民、家事」「汽車和房屋保險」），**不要抄評論裡的「一定會贏」「保證過件」「最便宜」**這類句子，示範站會把 notes 放在首頁。

## 地區
原本的：聖蓋博谷、Irvine、Cupertino、Fremont、Milpitas、舊金山、法拉盛、紐約市。

**11/27 新增**（都在美國，可以照一樣的方式找）：
- 華盛頓州：Seattle、Bellevue、Redmond（`WA`）
- 德州：Houston、Sugar Land（`TX`）
- 內華達州：Las Vegas（`NV`）
- 麻州：Boston、Quincy（`MA`）
- 伊利諾州：Chicago（`IL`）
- 賓州：Philadelphia（`PA`）

**不要找加拿大**（例如 Vancouver、Richmond BC、Toronto、Markham）：加拿大的反垃圾郵件法（CASL）對主動寄信有另外的規定，要先另外審查。

## 篩選（全部符合才收）
- 華人經營或主要服務華人客群，**下面任一個成立就算**（11/23 放寬）：
  - 店名、招牌、Google 商家頁面或菜單有中文
  - 評論裡有中文（不限最近 30 則）
  - 粉專、Instagram 或舊網站有中文
  - **（11/23 第二次放寬）醫師或老闆是華人姓氏**（例如 Dr. Lin、Zhang Dental、Wayne W Lee DDS、Huang's Acupuncture），**而且**店在華人多的地區：聖蓋博谷（San Gabriel、Alhambra、Arcadia、Monterey Park、Rosemead、Temple City、Rowland Heights、Diamond Bar、Walnut）、Irvine、Cupertino、Fremont、Milpitas、法拉盛、日落公園、曼哈頓唐人街、舊金山 Sunset／Richmond，以及上面「11/27 新增」地區裡的華人聚集區（Bellevue、Redmond、Sugar Land、Bellaire Blvd 一帶、芝加哥 Chinatown、波士頓 Chinatown／Quincy、費城 Chinatown、拉斯維加斯 Spring Mountain Rd 一帶；這些城市的其他區域**只有姓氏不算，一定要看到中文**）。符合這條的，在 notes 寫「華人姓氏」。
- Google 評價 **4.0 星以上、20 則以上**（11/23 從 50 則放寬）
- 網站狀態是下面其中一種：
  - `none`：Google 商家資料沒有網站
  - `social_only`：網站欄位只是 Facebook／Instagram／Yelp 頁面
  - `outdated`：有網站但很舊（手機版跑版、多年沒更新、只有一張菜單圖）
  - `english_only`：網站正常但只有英文
- 有**公開的聯絡方式**：Email、網站聯絡表單、Facebook 粉專或 Instagram（至少一種；Instagram 記在 contact_url）
- 已經有正常的中英文網站的店，**不要收**

## 每家要記錄的欄位（對應 sales/outreach/leads.csv）
| 欄位 | 怎麼填 |
|---|---|
| business | 店名（英文名；有中文名就寫「英文名 / 中文名」） |
| category | restaurant／dental／tcm／tutoring／salon／realestate／accounting／law／insurance |
| city | 城市 |
| address | Google 地圖上的地址 |
| phone | 店家電話 |
| email | 公開的商家 Email（Google、粉專「關於」、舊網站上找），沒有就空白 |
| contact_url | 聯絡表單網址或 Facebook 粉專網址 |
| google_maps_url | Google 地圖分享連結 |
| rating, reviews | 星等、評論數 |
| website, website_status | 網站網址（沒有就空白）、上面四種之一 |
| languages_seen | 評論或菜單裡看到的語言，例如 `en, zh-Hant, zh-Hans` |
| hours | **一定要填**。Google 地圖上的營業時間，例如 `Mon-Fri 11:00-21:00; Sat-Sun 10:00-22:00`（示範站會顯示「現在營業中」） |
| notes | 招牌菜、主要服務、評論常提到的優點（一句話，之後放進示範站） |
| status | 一律填 `new` |

## 回報格式
最後輸出一段 CSV（不要表頭，欄位順序和 leads.csv 相同，id 留空、date_found 填今天），使用者會貼給 Claude 加進名單。
另外列出「看過但沒收的店」和原因，一行一家。

## 找完之後：把 CSV 存到 GitHub（11/26 起）
不用下載檔案。直接：
1. 打開 `https://github.com/a0955072107-bit/polyglot-leads/new/main?filename=inbox/leads-<日期>.csv`（同一天第二批加 b，例：`leads-2026-11-26b.csv`）。
2. 把 CSV 完整內容（含表頭）貼進編輯框，不要省略欄位。
3. 「Commit changes」→「Commit directly to the main branch」。
4. 回報檔案網址和列數。使用者跟 Claude 說「名單好了」即可。


> 寄到美國的開發信一律要符合 CAN-SPAM：實體地址（Gmail 簽名已自動帶）＋退訂方式（信尾「回覆 no thanks 就不再寄」），見 `README.md`。
