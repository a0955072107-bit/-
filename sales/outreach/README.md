# 主動開發：美國華人店家（Polyglot Pages）

**目標**：美國華人店家，沒有網站、網站很舊，或網站只有英文的。賣「三語店家網站代製」$299（Pro $549）。
**地區**：舊金山灣區、洛杉磯聖蓋博谷（San Gabriel Valley）、紐約法拉盛（Flushing）、西雅圖、休士頓。
**行業**（依優先順序）：餐廳、牙醫／中醫診所、補習班、美容美髮。

## 流程（每家約 5 分鐘）

| 步驟 | 誰做 | 做什麼 |
|---|---|---|
| 1. 找名單 | 擴充功能 | 照 `擴充功能找名單.md` 在 Google 地圖找店，寫進 `leads.csv`（只查，不送訊息） |
| 2. 做示範 | Claude | `python3 scripts/demo/make-demo.py <lead_id>`，產生三語示範站，上傳到 Demo 網站的 `demo/<店>/` |
| 3. 寫信 | Claude | 依 `訊息範本.md` 為每家寫好一封，放進 `outbox/日期.md` |
| 4. 送出 | 你 | 從 polyglotpages.studio@gmail.com 複製貼上寄出（或用 FB 粉專私訊） |
| 5. 追問 | 你 | 4 天沒回覆追問一次，之後不再聯絡 |
| 6. 記錄 | 你／Claude | 更新 `leads.csv` 的 status |

## 每天的量
- 第 1 週：每天 10 家
- 第 2 週：每天 20 家
- 第 3 週起：每天 30 家，**每月 600 封以上**（新 Gmail 一天寄太多陌生信容易被判定垃圾信，30 是上限）
- 付款：先收 50% 訂金，客人確認網站後再收 50% 尾款（Gumroad Commission）

## 規則（美國 CAN-SPAM 法）
- 標題不能誤導，信裡要寫清楚是誰寄的。
- 每封信最後都附「不想再收到請回覆告訴我」，對方要求就立刻停止，status 改成 `optout`。
- 只聯絡商家公開的 Email、聯絡表單或粉專，不聯絡個人。
- **只做美國**。加拿大（CASL）、澳洲的規定比較嚴，之後另外處理。

## 示範網站
- 每個示範頁最上方都有一條說明：「這是 Polyglot Pages 做的預覽，不是官方網站」，並設定不讓 Google 收錄（noindex）。
- 只放店家公開的資料：店名、地址、電話、營業時間、類別。照片一律用模板的插圖，**不抓對方的照片**。
- 對方要求下架，當天刪除。
- 30 天沒成交的示範站自動清掉。

## 數字（每週看一次）
寄出 → 回覆 → 看過示範 → 成交。預期回覆率 5～10%。每週 50～150 家，大約每月 2～6 筆成交。

## status 欄位的值
`new`（剛找到）→ `demo`（示範做好）→ `sent`（已寄）→ `followup`（已追問）→ `replied`（有回覆）→ `won`（成交）／`lost`（不需要）／`optout`（要求不要再聯絡）
