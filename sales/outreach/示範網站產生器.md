# 示範網站產生器（怎麼用）

幫名單上的店家做一個「免費三語預覽網站」（英文、繁體、简体），放在 Demo 網站的 `demo/<店>/` 底下，寄信時附上網址。

## 第一次使用前
```
pip install opencc-python-reimplemented
```

## 做一家
```
python3 scripts/demo/make-demo.py <lead 的 id>
```
- 會讀 `sales/outreach/leads.csv` 那一列，依 `category` 選底稿：
  - `restaurant` → 餐廳
  - `dental` → 牙醫診所，`tcm` → 中醫針灸（同一個診所底稿，文字自動切換）
  - `tutoring` → 補習班
  - `salon` → 美髮店
  - `realestate`（也可寫 `real estate`、`realtor`）→ 房地產經紀
  - 專業事務所（同一個 consulting 底稿，服務項目、常見問題、頁尾聲明自動切換）：
    - `accounting`（也可寫 `cpa`、`tax`）→ 會計報稅：個人報稅、小商家報稅、記帳、小商家薪資、新公司設立、IRS 信件
    - `law`（也可寫 `lawyer`、`immigration`、`attorney`）→ 律師事務所：移民、家事、公司設立、合約、房地產、遺囑信託
    - `insurance` → 保險代理：汽車、房屋與租屋、人壽、健康、商業保險、保單健檢
  - 寫了不認得的 category，產生器會停下來並列出所有可以用的寫法。
- 做好的檔案在 `demos/<店名-城市>/`，裡面有 `index.html`（依瀏覽器語言自動跳轉）和 `en/`、`zh-TW/`、`zh-CN/`。
- 會自動把那一列的 `demo_url` 填成 `demos/<店名-城市>/`，`status` 改成 `demo`。
- 用別的名單檔：加 `--csv 路徑`。

## 一次做完所有新名單
```
python3 scripts/demo/make-demo.py --all-new
```
會做 `status` 是 `new` 的每一家。

## 中文店名、中文介紹
- 店名寫成 `英文名 / 中文名`（例如 `Golden Leaf Dumpling House / 金葉餃子館`），中文版就會用中文店名，英文版用英文店名。
- `notes`（招牌菜、評論常提到的優點）會放在首頁大標題下面。英文版直接用英文句子。
- 中文版只有在**有中文店名**時才放 notes 的中文翻譯，沒有中文店名就用通用句子。中文翻譯可以：
  - 直接寫在 notes 裡：`英文句子 / 中文句子`，或
  - 做的時候加上：`--notes-zh "招牌是手工水餃和紅油抄手。"`（寫繁體，简体版會自動轉換）

## 營業時間的寫法
`Mon-Fri 11:00-21:00; Sat-Sun 10:00-22:00`
- 用分號隔開，每段是「星期 時間」。也可以寫 `Daily 11:00-22:00`、`Mon closed`、`Tue-Sun 11:00-15:00, 17:00-21:00`（中午休息）。
- 看不懂的寫法（例如 `by appointment`）不會出錯，網站會改放「營業時間請來電」，產生器也會提醒。

## 產生器會自動處理的事
- 店名、地址、電話（可以直接點撥）、Google 地圖連結（用名單上的 `google_maps_url`）、營業時間、城市名稱（常見城市會用中文，例如法拉盛、聖蓋博）。
- 每一頁最上方都有一條說明：「這是 Polyglot Pages 免費製作的網站預覽，不是 XX 的官方網站」和我們的 Email。
- 每一頁都設定不讓 Google 收錄（noindex），網站的 `robots.txt` 也擋掉 `/demo/`。
- 不會放假評價、假年資、假員工名字。菜單、價目、課程都標明「範例」，評價區只放 Google 地圖和 Yelp 的連結。
- 房地產：物件卡片、價格都標「範例」，頁尾寫明「物件是範例，不是真實房屋」；執照號碼、經紀公司名稱和 Equal Housing Opportunity 只留「範例」位置（多數州規定要放，正式網站要請客人提供）。不放成交數字。
- **律師和保險的網站常常不能寫保證結果**：律師廣告有各州律師公會的規範（不能承諾案件結果、通常要標「Attorney advertising」），保險不能寫「最便宜」或保證理賠。底稿已經：不寫任何結果或保證、律師版頁尾有「律師廣告／不構成法律意見／不成立委任關係／過去結果不保證類似結果」、保險版頁尾有「保障以保單條款為準」。**寄信或改文案時也不要加上「保證」「一定」「勝訴率」「最低價」這類字眼**；客人要上線前，請他自己確認所在州的規定。
- **不會抓店家的照片**，圖片都是模板自己的插圖。微信（WeChat）只留一個「範例」位置，因為我們不知道店家的微信號。

## 上線
```
bash scripts/build-site.sh
```
`demos/` 會被複製到 `_site/demo/`，所以網址是 `<Demo 網站網址>/demo/<店名-城市>/`。推上 GitHub 後就能寄信。

## 清掉不需要的示範站
```
python3 scripts/demo/cleanup.py --dry-run   # 先看會刪哪些
python3 scripts/demo/cleanup.py             # 真的刪除（預設 --days 60）
```
- `status` 是 `optout`（要求不要聯絡）或 `lost`（不需要）的，馬上刪。
- 寄出後超過 60 天（沒寄過的從做好那天算）、`status` 不是 `won`／`replied` 的才刪；`later`、`followup` 保留到 `followup_date` 後 14 天。
- 刪掉後會清空名單上的 `demo_url`，再跑一次 `bash scripts/build-site.sh` 並推上去，網站上的預覽才會消失。
- 對方要求下架：把 `status` 改成 `optout`，跑 `cleanup.py`，再重新建置上傳。當天處理。

## 寄出前自己看一眼
- 打開 `demos/<店>/en/`、`zh-TW/`、`zh-CN/` 各看一次：店名、地址、電話、營業時間對不對。
- 產生器有印出「!」提醒的（例如時間看不懂、地址格式不對），先在 `leads.csv` 改好再重做一次。重做會直接覆蓋舊的。

## 底稿在哪裡
- `scripts/demo/base/<餐廳 restaurant／診所 clinic／補習班 education／美髮 beauty／房地產 realestate／專業事務所 consulting>/{en,zh-TW,zh-CN}/index.html`
- 有分版本的底稿用 `<!--IF:版本-->…<!--/IF:版本-->` 標記（clinic：dental、tcm；consulting：accounting、law、insurance），產生器只留下該版本的區塊。
- 改中文內容時只改 `zh-TW`，再執行 `python3 scripts/demo/make-base-zh-cn.py` 產生 `zh-CN`，然後用眼睛看一次简体版。
- 販售的模板在 `templates/`，產生器不會動到它們。
