## 給擴充功能的規則（每次都要遵守）

1. **只建草稿，不要按 Publish**。每個商品存成草稿，最後由使用者自己檢查、發布。
2. 開始前確認畫面右上或左下的商店是**新商店**，不是「收入飛輪研究…」。不確定就停下來問。
3. 所有欄位內容照 `sales/Gumroad上架步驟.md`（同一個 GitHub 分支）對應的段落，**一字不改**複製。網址：
   `https://github.com/a0955072107-bit/-/blob/main/sales/Gumroad上架步驟.md`
4. **封面圖：先試著自己從網址上傳**（見下方「封面自動上傳」）。成功就繼續；失敗就停下來請使用者拖。**zip 一律由使用者拖**（zip 是付費商品，沒有放在網路上）。
5. 遇到付款、身分驗證、刪除、改帳號設定的畫面，**一律停下來問**，不要自己按。
6. 一個商品做完就回報一行：商品名稱、URL slug、價格、版本、哪些欄位已填、還缺什麼。
7. 商店：Polyglot Pages（`polyglotpages.gumroad.com`）。客製服務的 URL slug 一定要是 `website-customization`，因為其他商品說明裡已經寫好 `https://polyglotpages.gumroad.com/l/website-customization`。聯絡 Email：`polyglotpages.studio@gmail.com`。

## 封面自動上傳（給擴充功能）

封面放在公開網址：`https://a0955072107-bit.github.io/-/covers/<檔名>`
（例：`restaurant-cover.png`、`restaurant-thumb.png`；Motion 款是 `motion-wedding-cover.png` 這種格式）

做法：
1. 在 Gumroad 商品編輯頁，先點封面區的「Upload」或「+」，讓頁面出現上傳框（不用在跳出的選檔視窗選檔，按取消關掉即可）。
2. 在頁面執行這段 JavaScript（把檔名換成這個商品的封面）：
```js
(async () => {
  const name = 'restaurant-cover.png';
  const blob = await (await fetch('https://a0955072107-bit.github.io/-/covers/' + name)).blob();
  const file = new File([blob], name, { type: 'image/png' });
  const inputs = [...document.querySelectorAll('input[type=file]')];
  const input = inputs.find(i => (i.accept || '').includes('image')) || inputs[0];
  const dt = new DataTransfer(); dt.items.add(file);
  input.files = dt.files;
  input.dispatchEvent(new Event('change', { bubbles: true }));
  return inputs.length + ' file inputs; used: ' + (input.accept || 'no accept');
})();
```
3. 等幾秒，確認封面真的出現在預覽裡、也儲存成功。
4. **沒有出現**就不要再試，停下來請使用者手動拖，並回報畫面上看到的錯誤。

縮圖（Thumbnail，正方形）一樣做法，檔名換成 `<款式>-thumb.png`。
