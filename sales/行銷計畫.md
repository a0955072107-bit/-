# 行銷計畫：國外需求、定價、推廣、連結

## 1. 國外需求

國外買模板的人主要有兩種：
- **自己開店的小老闆**：想要便宜、快速、不用月費的網站。
- **幫客戶架站的接案者**：會買延伸授權或全套組合包。

國外大家用英文搜尋，所以商品標題、說明、Demo 都以英文為主。

### 國外比較好賣的類型
| 類型 | 我們有嗎 |
|---|---|
| SaaS／App 登陸頁 | ✓ |
| 個人作品集／履歷 | ✓ |
| 婚禮網站 | ✓ |
| 餐廳、房仲、健身、攝影師 | ✓ |
| 心理諮商／生活教練（therapist / coach） | 下一批建議做 |
| 水電／修繕師傅（contractor / handyman） | 下一批建議做 |
| 教會／非營利組織 | 下一批建議做 |
| Link-in-bio 個人連結頁 | 下一批建議做 |

### 免費確認需求的方法
- 在 Etsy 搜尋關鍵字，看有多少商品標示「Bestseller」，以及評論數。
- 用 Google Trends 比較關鍵字熱度。
- 上架後看 Gumroad 後台每款的瀏覽數和轉換率，賣得好的就多做同類型。

## 2. 定價（Gumroad，美元）

| 商品 | 價格 |
|---|---|
| 單一模板（1 個網站授權） | $39（上市優惠 $29） |
| 延伸授權（最多 10 個網站） | $119（上市優惠 $89） |
| 全套 22 款 | $199（上市優惠 $149） |
| 客製服務 Basic | $249 |
| 客製服務 Plus | $449 |

- 上市前 2 週全店打 7 折（折扣碼，例如 `LAUNCH30`），先衝第一批評價。
- Gumroad 後台的 **購買力平價（PPP）** 選項建議打開。
- Etsy 上競爭比較激烈，同一款可以定 $19～29。
- 定價理由：中英雙語、有互動功能、附完整教學、買斷不用月費。要比較的對象是 Framer／Webflow 模板（$49～129，而且要月費），不是 $15 的單語 HTML 模板。
- 上架後看數據調整：瀏覽很多卻沒人買的款式降到 $29，賣得好的維持原價。
- 台灣的客製服務可以另外報價，例如 NT$6,000～15,000。

## 3. 推廣管道（依效果排序）

1. **Pinterest**：模板類最強的免費長期流量。每款做 3～5 張直式圖（1000×1500），連到 Gumroad 商品頁。
2. **Etsy 同步上架**：Etsy 有站內搜尋流量。
3. **短影片**：IG Reels、TikTok、YouTube Shorts，內容是「10 分鐘把模板改成你的店」或滑動展示 Demo。
4. **免費款引流**：拿 1 款設成「$0+ 自由付費」來收集 Email，之後新品上架再寄信通知。
5. **Dribbble／Behance**：放精美截圖，個人簡介連到商店。
6. **社群**：Reddit（r/smallbusiness、r/webdev）、Indie Hackers。分享做模板的過程，不要直接貼廣告。
7. **Gumroad Affiliates**：開放別人幫你推廣，付 20～30% 佣金。
8. **台灣**：FB 接案社團、Threads、Dcard，主打客製服務。

### 每週固定要做的事（建議）
- 每週上架 1～2 款新模板，讓商店持續有新品。
- 每天發 1～2 張 Pinterest 圖。
- 每週發 1 支短影片。

## 4. 網址要放在哪裡

| 位置 | 要不要放 |
|---|---|
| 商品說明裡的 Demo 網址 | ✅ 一定要放 |
| 展示頁網址 | ✅ 可以放 |
| Etsy 商品頁的 Gumroad 或自己網站的購買連結 | ❌ 違反 Etsy 規定，只能放 Demo |
| 付費模板頁尾的「Made by 我們」連結 | ❌ 買家會反感 |
| 免費款頁尾的小連結 | ✅ 免費款就靠這個帶流量 |

**建議買自己的網域**（例如 `xxxtemplates.com`，一年約 US$10），在 GitHub Pages 設定 Custom domain。網址好記，看起來也比較專業。
