# 行銷計畫：國外需求、定價、推廣、連結

## 1. 國外需求

國外買模板的人主要有兩種：
- **自己開店的小老闆**：想要便宜、快速、不用月費的網站。
- **幫客戶架站的接案者**：會買延伸授權或全套組合包。

國外大家用英文搜尋，所以商品標題、說明、Demo 都以英文為主。

### 國外比較好賣的類型
| 類型 | 我們有嗎 |
|---|---|
| SaaS／App 登陸頁 | ✓ |
| 個人作品集／履歷 | ✓ |
| 婚禮網站 | ✓ |
| 餐廳、房仲、健身、攝影師 | ✓ |
| 心理諮商／生活教練（therapist / coach） | ✓ |
| 水電／修繕師傅（contractor / handyman） | ✓ |
| 教會／非營利組織 | ✓ |
| Link-in-bio 個人連結頁 | ✓ |

### 免費確認需求的方法
- 在 Gumroad Discover、Creative Market 搜尋關鍵字，看熱門商品的評論數。
- 用 Google Trends 比較關鍵字熱度。
- 上架後看 Gumroad 後台每款的瀏覽數和轉換率，賣得好的就多做同類型。

## 2. 定價（Gumroad，美元）

| 商品 | 價格 |
|---|---|
| 單一模板（1 個網站授權） | $39（上市優惠 $29） |
| 延伸授權（最多 10 個網站） | $119（上市優惠 $89） |
| 全套 30 款 | $249（上市優惠 $199） |
| 客製服務 Basic | $249 |
| 客製服務 Plus | $449 |
| 三語店家網站代製 | $299／$549 |
| 全套工作室無限授權 | $399（上市優惠 $299） |

- 上市前 2 週全店打 7 折（折扣碼，例如 `LAUNCH30`），先衝第一批評價。
- Gumroad 後台的 **購買力平價（PPP）** 選項建議打開。
- 定價理由：中英雙語、有互動功能、附完整教學、買斷不用月費。要比較的對象是 Framer／Webflow 模板（$49～129，而且要月費），不是 $15 的單語 HTML 模板。
- 上架後看數據調整：瀏覽很多卻沒人買的款式降到 $29，賣得好的維持原價。
- 台灣的客製服務可以另外報價，例如 NT$6,000～15,000。

## 3. 推廣管道（依效果排序）

1. **Pinterest**：模板類最強的免費長期流量。每款做 3～5 張直式圖（1000×1500），連到 Gumroad 商品頁。
2. **小紅書**：主攻海外華人與新馬店家的三語代製服務（Etsy 不支援台灣賣家收款，已移除）。
3. **短影片**：TikTok、YouTube Shorts（不做 IG，11/22 決定），內容是「10 分鐘把模板改成你的店」或滑動展示 Demo。
4. **免費款引流**：拿 1 款設成「$0+ 自由付費」來收集 Email，之後新品上架再寄信通知。
5. **Dribbble／Behance**：放精美截圖，個人簡介連到商店。
6. **社群**：Reddit（r/smallbusiness、r/webdev）、Indie Hackers。分享做模板的過程，不要直接貼廣告。
7. **Gumroad Affiliates**：開放別人幫你推廣，付 20～30% 佣金。
8. **台灣**：FB 接案社團、Threads、Dcard，主打客製服務。

### 每週固定要做的事（建議）
- 每週上架 1～2 款新模板，讓商店持續有新品。
- 每天發 1～2 張 Pinterest 圖。
- 每週發 1 支短影片。

## 4. 網址要放在哪裡

| 位置 | 要不要放 |
|---|---|
| 商品說明裡的 Demo 網址 | ✅ 一定要放 |
| 展示頁網址 | ✅ 可以放 |
| 付費模板頁尾的「Made by 我們」連結 | ❌ 買家會反感 |
| 免費款頁尾的小連結 | ✅ 免費款就靠這個帶流量 |

**建議買自己的網域**（例如 `xxxtemplates.com`，一年約 US$10），在 GitHub Pages 設定 Custom domain。網址好記，看起來也比較專業。


## 5. 客製案的客人從哪裡來（主要收入）

1. **Fiverr／Upwork**：國外小老闆找人做網站最常用的平台。開一個「I will build your business website」服務，作品集放我們的模板 Demo。這是最快接到國外案子的管道。
2. **台灣接案平台**：Tasker 出任務、104 外包網、PRO360 達人網。
3. **主動開發**：在 Google 地圖搜尋行業關鍵字，找出「有評價、但沒有網站」的店家，私訊附上一個用他們店名做好的 Demo（用我們的模板，改 10 分鐘就能做好）。
4. **FB 社團**：在地店家社團、創業社團，用分享經驗的方式曝光。
5. **模板買家**：沒時間自己改的買家會直接找你客製。模板賣得越多，客製案就越多。

## 7. 下一步：Motion 動態系列（高價產品線）

| 系列 | 價格 |
|---|---|
| 標準款 | $39 |
| Motion 動態款 | $59～79 |
| Motion 全套 | $199 起 |

- 內容：捲動視差、跟著捲動播放的動畫、文字逐字出現、圖片遮罩展開、游標互動、WebGL 首屏背景。
- 技術：只用瀏覽器內建的動畫技術，**不使用 GSAP 等第三方函式庫**。GSAP 放進模板轉售給多人是否符合它的授權條款，目前無法確定；用內建技術可以避開授權風險，檔案也比較小。
- 必須做到：手機上流暢不卡；使用者開啟「減少動態效果」時自動關閉動畫。
- 第一批 Motion（製作中）：SaaS 登陸頁、作品集、餐廳、婚禮、房仲。上市時程見 `sales/營運流程.md`。


## 8. 更多市場（依優先順序）

### 語言與地區
| 市場 | 為什麼 | 在哪裡曝光 |
|---|---|---|
| 日本（日文） | 願意為設計付費，客單價高 | ココナラ、BOOTH、note、Pinterest、X |
| 西語圈（西班牙文） | 人口超過 5 億，競爭比英文少 | Gumroad、Hotmart、Workana、YouTube 西語教學 |
| 巴西（葡萄牙文） | 數位商品市場活躍 | Hotmart、Instagram |
| 韓國（韓文） | 美業、咖啡廳特別多 | 크몽 Kmong、Instagram |
| 歐洲（德文、法文） | 購買力高；要處理 GDPR，德國網站要有 Impressum | Gumroad、Creative Market |
| 新馬（簡體＋英文） | 天生需要雙語 | 小紅書、Facebook 社團、Carousell |
| 東南亞 | 小店多，價格要低 | Facebook、TikTok |

### 產品格式（可能比加語言更大）
| 格式 | 說明 |
|---|---|
| WordPress 佈景主題 | 全球約 40% 的網站在用；可上 ThemeForest |
| Framer／Webflow 模板 | 官方市集自帶流量，可定 $49～129 |
| Shopify 主題 | 審核嚴，但賣得起來就很好賺 |
| Notion／Canva 版本 | 價格低，量大 |

### 客戶類型
- 接案者、小型設計公司：延伸授權、全套組合包（Gumroad Discover、Creative Market、Reddit、Indie Hackers）
- 海外華人店家（美加澳紐）：中英雙語剛需（華人商會、華人 FB 社團、微信社群）
- 非營利、教會：預算少但長期合作

### 建議順序
先上架並觀察 2～4 週 → 加日文、西班牙文 → 做 Framer 版 → 做 WordPress 版。
