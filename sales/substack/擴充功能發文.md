# 用 Chrome 擴充功能把文章存成 Substack 草稿（給 Claude in Chrome／Cowork 讀）

> 使用者：先在 Chrome 登入 Substack（polyglotpages.studio@gmail.com），擴充功能新對話貼上：
> 「照 https://github.com/a0955072107-bit/-/blob/main/sales/substack/擴充功能發文.md 把第 N 篇存成 Substack 草稿。」

## 規則
1. **只存草稿，不要按 Publish／Send**。使用者看過後自己發布。
2. 文章在 `https://github.com/a0955072107-bit/-/tree/main/sales/substack/posts`，第 N 篇就是檔名開頭 `0N-` 的那個檔案。
3. 第一行 `# ` 後面是**標題**；`*Subtitle: …*` 是**副標題**（填進副標題欄，不放進內文）；其餘是內文。
4. 內文照原文貼上：`## ` 是小標題、`**粗體**`、清單、程式碼區塊和連結都要保留格式。不要改寫任何字。
5. 文章裡的 `👉` 那一行是連結，確認連結可以點。
6. 不要上傳圖片、不要改設定、不要動訂閱者名單。遇到登入驗證或付款畫面就停下來問。
7. 存好後回報：草稿標題、副標題、連結數量，以及編輯器預覽是否正常。

## Notes
使用者說「發第 X 週第 Y 天的 Note」時：打開 Substack Notes，貼上 `sales/substack/notes.md` 對應的那一則，**不要按發布**，請使用者自己按。
