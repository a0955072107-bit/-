## A. clinic（安和牙醫）

**方向**：保留「藍綠＝牙醫」的辨識，但更沉、更安靜；跟第二款（森林診間，襯線＋綠）區隔：這款維持**無襯線、資訊清楚**的路線。

### 主題變數（取代原本的值；變數名稱可增減，但每個都要中文註解）
| 變數 | 新值 | 用途 |
|---|---|---|
| `--brand` | `#0F5E58` | 深藍綠：按鈕、重點 |
| `--brand-deep` | `#0B403C` | hover、深色區塊 |
| `--brand-soft` | `#E4EEEC` | 淺底 |
| `--bg` | `#F5F7F6` | 瓷白頁面底 |
| `--surface` | `#FBFCFB` | 表面 |
| `--text` | `#17252A` | 文字 |
| `--muted` | `#4E5D63` | 次要文字 |
| `--line` | `#DCE3E1` | 細線 |
| `--closed` | 維持 `#8a5a12` 系，確認 AA | 休診 |
| `--radius` | `10px`；`--radius-sm` `6px` | 圓角收小 |
| 字體 | 標題 `Instrument Sans` 500/600 ＋ `Noto Sans TC` 500；內文 `Noto Sans TC` 400 | 取代 Plus Jakarta Sans；標題不超過 600 |
- 刪除 `--aqua`、`--sky` 這類只為泡泡佔位圖存在的色，改用 brand／brand-soft／surface 的 color-mix。
- 陰影只留一種、很淡（以 `--text` 調 6～8%）。

### 逐項
1. **C1 首屏圖**：佔位圖改成「診間」構圖：大窗（淺色光）、診療椅側面的簡單幾何（2～3 個圓角矩形）、一盞吊燈線條；比例 4:5、圓角 `--radius`；拿掉十字與牙齒輪廓。**手機**：今日門診卡片排在按鈕下方、圖片之前（用 `order`），圖片高度約 220px。
2. **C2 診療項目**：6 張卡改成 2 欄清單（每項：小圖示 20px＋名稱＋一行說明，項目之間 1px 細線，無卡片底、無陰影、無 hover 上浮）。手機 1 欄清單，整區不超過約 1.3 個螢幕高。
3. **C3 醫師**：照片佔位改成無人形的拱形框（`border-radius: 999px 999px var(--radius) var(--radius)`）＋柔光漸層；比例 4:5。每位醫師加一行「看診時段」（例如「週一、三、五 早診」），內容要和門診表一致。
4. **C4 門診表手機版**：760px 以下隱藏表格，改顯示由 JS 從同一張表產生的「依星期分組清單」（每天一個 `<details>`，今天預設展開、標「今天」）。沒有 JS 時維持原表格＋橫向捲動。JS 總行數仍需在約 80 行內。
5. **C5 區塊開場多樣化**：門診表區：標題與「今天是週X」同一列左右排；交通區：地址用大字（標題字體、約 1.6rem）當開場，h2 保留但視覺較小。
6. **C6 動畫**：只保留首屏一次進場；其他區塊移除 `.reveal`。
7. **C7 首屏特點**：文字 ✓ 改成 14px SVG 勾號，`display:flex; flex-wrap` 對齊整齊。
8. **C8**：加「跳到主要內容」skip link（各語言翻譯）。
9. **高級感**：按鈕改 8px 圓角（不用膠囊）；區塊上下 `clamp(5rem, 11vw, 8.5rem)`；h1 字重 600、h2 500～600；所有分隔用 1px `--line`。

## B. restaurant（日和食堂）

**方向**：離開「奶油底＋赤陶＋Fraunces」AI 預設。日式家常食堂的語彙：青磁、抹茶、和紙的冷調白、柚子黃點綴，安靜、乾淨、有溫度。

### 主題變數
| 變數 | 新值 | 用途 |
|---|---|---|
| `--brand` | `#2F4A3A` | 深抹茶：按鈕、重點 |
| `--brand-ink` | `#F7F8F4` | brand 上的文字 |
| `--bg` | `#ECEEE8` | 青磁灰白頁面底（偏冷，不是奶油色） |
| `--surface` | `#F7F8F4` | 表面 |
| `--text` | `#1F2420` | 墨色文字 |
| `--muted` | `#59605A` | 次要文字 |
| `--line` | `#D5D9D0` | 細線 |
| `--accent` | `#C99A1E` 柚子黃 | 唯一點綴（招牌標籤、營業中狀態旁的小標記），面積 ≤ 5%；當文字色時要確認 AA，不夠就只當底色或邊框 |
| `--open` | 深綠，確認 AA | 營業中 |
| 佔位圖用色 | 木、盤、醬汁、香草、莓果可保留但降低彩度，木色偏淺（白橡木） | |
| `--radius` | `8px` | |
| 字體 | 標題 `Spectral` 500（拉丁）＋ `Noto Serif TC` 500；內文 `Noto Sans TC` 400；英文／西文版內文用 `Figtree` 400/500 | 取代 Fraunces |
- 日文版：標題 `Shippori Mincho` 500、內文 `Zen Kaku Gothic New`（維持現狀，只調字重）。
- `theme-color` meta 改成新 `--brand`。

### 逐項
1. **R1 配色字體**：如上。
2. **R2 首屏**：移除「2016／4.8★／NT$300+」數據列。保留營業狀態膠囊與「本週主廚推薦」小卡。
3. **R3 相簿空格**：改用 `grid-template-areas`：桌機 4 欄 2 列 `"a a b c" "a a d e"`；手機 2 欄 `"a a" "b c" "d e"`。確認 1440、1280、390 都沒有空格。
4. **R4 首屏圖**：拿掉拱形，改 4:5、圓角 `--radius` 的俯拍構圖：白橡木桌、斜射自然光（大面積柔和亮暗漸層）、一盤主菜＋一雙筷子（兩條細長矩形）＋一個小碟；減少卡通色點。蒸氣動畫保留（唯一動態記憶點），reduce motion 時停止。
5. **R5 關於我們**：三張特色卡改成三行文字清單（名稱粗一階＋一句說明，行間 1px 細線），拿掉圖示方塊與卡片。
6. **R6 評價**：改成一則大型引言（標題字體、約 1.5rem）＋兩則小引言並排；星等用小字 `aria-label` 保留；保留「範例內容」註解。
7. **R7 換行**：內文 `p` 加 `text-wrap: pretty`；日文版加 `word-break: auto-phrase`。
8. **R8 動畫**：只保留首屏進場與蒸氣；其他區塊移除 `.reveal`。
9. **高級感**：按鈕 6px 圓角（不用膠囊）；菜單分頁改成「文字＋底線」樣式（目前分頁有底線），不用實心膠囊；區塊上下 `clamp(5rem, 11vw, 8.5rem)`；h1 字重 500；卡片陰影移除，改 1px 細線。
