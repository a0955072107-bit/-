# 牙醫診所第二款：設計提案（2026-11-29 製作）

> **使用者 2026-11-25 選定：方向 A 森林診間。** 定稿的設計計畫見文末「定稿：方向 A」。

> 內部用，打包時不會放進商品。
> **示意圖**（首屏桌機＋手機）：`research_notes/牙醫第二款示意圖/示意圖-A.png`、`-B.png`、`-C.png`，原始 HTML 在同一個資料夾。示意圖已依「高級感」標準（DESIGN.md 2.9）升級過，只用來選方向，不是成品。依 `DESIGN.md` 第 1 節的「設計計畫」格式。
> 現有 clinic（安和牙醫）是：藍綠 #0f766e、Plus Jakarta Sans＋Noto Sans TC、圓角卡片、左字右圖首屏、門診表在中段。
> 第二款要「一眼看得出不同」，不只是換色。三個方向都避開 DESIGN.md 第 3 節的 AI 預設組合。

所有方向共通：
- 繁中版遵守《醫療法》：不放見證、前後對比、優惠；英文版可放評價區（標註範例內容）。
- 「今日門診」仍由同一份門診表用 JS 產生（只改一個地方），這是我們相對市集模板的優勢。
- 佔位圖要畫出「放什麼照片」的構圖，不是抽象色塊。
- **高級感（使用者指定，三個方向都要有）**：標題字重 400～500、按鈕小圓角或膠囊但只有一個實心、1px 細線取代粗框與重陰影、點綴色面積 ≤ 5%、桌機區塊間距 ≥ 120px、不用星星貼紙等卡通裝飾。詳見 DESIGN.md 2.9。

## 方向 A：森林診間（安靜、自然光、像精品診所）

**一句話**：像走進一間有窗、有植物、光線柔和的診間，讓怕看牙的大人放鬆。

| 項目 | 內容 |
|---|---|
| 配色 | 松綠 `#24433A`（品牌、深色區塊）／霧鼠尾草 `#E3EAE2`（區塊底）／石白 `#F4F5F1`（頁面底，偏冷不偏黃）／墨綠黑 `#17241F`（文字）／杏桃 `#E9A77F`（唯一點綴：今日看診中、按鈕 hover） |

| 版面 | 首屏是滿版「診間窗景」佔位圖，文字與按鈕疊在左下的半透明面板上；接著「第一次來看診」三步驟（真的是流程，可以編號）；診療項目是一欄清單＋細分隔線（不用卡片）；醫師用拱形相框；最後地圖＋門診表並排 |

## 方向 B：親子小牙醫（明亮、圓潤、給家長看）

**一句話**：家長一看就知道「這間對小孩很友善」，資訊依家庭成員分好。

| 項目 | 內容 |
|---|---|
| 配色（高級感版） | 霧白 `#F6F7F4`（頁面底）／深海軍 `#1E2B45`（文字、主要按鈕）／蜂蜜黃 `#E9C46A`（只用在 logo 與一個小圓點）／陶玫瑰 `#D98E7A`（照片構圖點綴）／霧薄荷 `#DCE8E1`（照片底色、輔助區塊）。原本的亮黃大色塊與珊瑚色改為低彩度，避免顯得幼稚 |
| 字體（高級感版） | 標題：Young Serif（英，圓潤的襯線，溫暖但不幼稚）＋ Noto Serif TC 500（中）；內文：Nunito Sans ＋ Noto Sans TC；日文：Shippori Mincho ＋ Zen Maru Gothic |
| 版面（高級感版） | 首屏左字右圖，圖是大拱形親子照片框＋一個細線圓；特點用細直線分隔的文字（不用膠囊標籤）；診療項目依「孩子／大人／長輩」三個分頁切換，項目用細線清單；「小朋友第一次看牙」準備清單；不用波浪與星星貼紙 |

## 方向 C：門診看板（精準、好讀、長輩友善）

**一句話**：首屏就是「今天誰看診、現在能不能掛號」，像車站時刻表一樣一眼看懂。

| 項目 | 內容 |
|---|---|
| 配色（高級感版） | 紙灰 `#F1F1EE`（頁面底）／墨藍 `#14213D`（文字、看板底）／深靛 `#273C9E`（品牌、按鈕，比原本鈷藍沉穩）／琥珀橘 `#C2410C`（只用在「看診中」，旁邊一定有文字）／霧灰藍 `#E6E8EF`（表格今天欄） |
| 字體（高級感版） | 全站一個字族：Schibsted Grotesk（英）＋ Noto Sans TC（中），標題 500、不用粗黑體，靠字級與留白做層級；數字 `tabular-nums`；日文 Noto Sans JP。內文 18px，長輩好讀 |
| 版面 | 首屏左邊是大標題＋預約按鈕，右邊是深墨藍「今日門診看板」（大字時段、醫師、狀態，JS 自動更新），手機上看板就在按鈕下方；診療項目是「項目／說明／健保或自費」索引表；門診表在手機改成「依星期展開」的清單；交通區大字地址＋地圖按鈕 |
| 記憶點 | 首屏的門診看板（把現有款藏在中段的資訊變成主角） |
| 適合 | 健保門診量大、長輩多、多位醫師輪班的診所；功能取向的買家 |
| 風險 | 容易變成「後台儀表板」感，要用適度圓角（8px）和留白保持溫度；不要走報紙細線零圓角風 |

## 我的建議

**A（森林診間）**：跟現有款差異最大（滿版圖首屏、襯線、清單式），也最符合 2026 參考範例的方向（暖、像精品、有真實感）；而且英文版賣給美國華人診所時質感最好。
如果想把「功能」當賣點、跟市集模板拉開距離，**C** 是第二選擇；B 適合之後做「兒童牙科」專款。

## 定稿：方向 A 森林診間（2026-11-25）

### 基本
- **slug**：`dental`（繁中 `templates/dental/`，其他語言照 SPEC 放 en／zh-CN／ja）。
- **店家（虛構）**：青窗牙醫診所（台中西區）；英文版 Aoi Window Dental（虛構美國地址）。
- **對象與任務**：怕看牙、在意「先說清楚再治療」的成人與家長；主要動作是 LINE／電話預約。
- **記憶點（只有一個）**：首屏的「有光的診間」大圖。其他區塊安靜。

### 配色（相對提案的調整）
| 名稱 | hex | 用途 |
|---|---|---|
| 松綠 | `#24433A` | 品牌色、按鈕、深色區塊（跟重做版 clinic 的藍綠 #0F5E58 明顯不同：偏綠、偏暗） |
| 霧鼠尾草 | `#E3EAE2` | 區塊底色 |
| 石白 | `#F4F5F1` | 頁面底（偏冷，不是奶油色） |
| 墨綠黑 | `#17241F` | 文字 |
| 淡黃銅 | `#C9B27C` | **唯一點綴**（取代杏桃，避開暖陶色預設）：標題下細線、目前語言底線；面積 ≤ 5%，不當文字色 |

### 字體
- 標題：Newsreader 500（英）＋ Noto Serif TC 500（中）；日文 Shippori Mincho 500。
- 內文：Figtree 400（英）＋ Noto Sans TC 400（中）；日文 Zen Kaku Gothic New。
- 跟 clinic（全無襯線、資訊感）做出區隔。

### 版面
1. 首屏：滿版診間圖，標題＋一句說明＋2 個按鈕疊在左下淺色面板（手機：圖在上、面板在下）。
2. 第一次來看診：三步驟（真的是流程，可以編號）。
3. 診療項目：一欄清單＋細分隔線（不用卡片）。
4. 醫師：拱形相框 ×3（拱形是這款的語彙；clinic 已改直角）＋看診時段。
5. 診所環境：2 張橫幅照片並排（候診區、諮詢室）。
6. 門診時間（今日門診由同一張表 JS 產生）＋交通與地圖。
7. 頁尾。

### 預設值自我檢查
- 原本想到「奶油底＋襯線＋杏桃」：杏桃屬暖陶色系預設 → 改淡黃銅，底色維持偏冷石白。
- 「滿版圖＋疊卡」本身常見 → 疊卡只放必要內容（標題、說明、2 按鈕），不放評分或數據。
- 拱形相框是記憶點的延伸，不再用在其他地方，避免變成裝飾。
