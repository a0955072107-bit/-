# セットアップガイド

ご購入いただきありがとうございます。このガイドに沿って進めれば、30 分ほどでサイトをあなたのお店仕様に変更し、公開できます。プログラミングの知識は必要ありません。

---

## 1. ファイルの内容

```
index.html           ← 言語の入口：訪問者のブラウザの言語に合わせて自動で振り分けます
ja/index.html        ← 日本語版（サイト全体がこの 1 ファイルです）
en/index.html        ← 英語版
zh-TW/index.html     ← 繁体字中国語版
zh-CN/index.html     ← 簡体字中国語版
*/images/            ← 写真用フォルダ（言語ごとに 1 つ）
ガイド.md            ← このガイド（GUIDE.md は英語版です）
利用規約・ライセンス.md ← できること・できないこと（LICENSE.md は英語版です）
プライバシーポリシー雛形.md ← プライバシーポリシーのひな形
```

各ページのヘッダーには **EN / 繁 / 简 / JA** の言語切り替えがあります。すべての言語を使う場合はフォルダごとアップロードしてください。日本語だけでよい場合は `ja/` フォルダだけをアップロードし、切り替えボタンから使わない言語のリンクを削除します（`lang-switch` で検索すると見つかります）。

**ある言語の文章を変更したら、他の言語も忘れずに更新してください。**

## 2. 必要なツール（すべて無料）

- テキストエディタ：[VS Code](https://code.visualstudio.com/) がおすすめです。Windows の「メモ帳」や Mac の「テキストエディット」でも編集できます。
- ウェブブラウザ：Chrome、Edge、Safari、Firefox のいずれか。

`ja/index.html` をブラウザで開くとサイトが表示されます。編集したら保存し、ブラウザを再読み込みすると変更が反映されます。

## 3. 文章を変更する

エディタで `index.html` を開き、`Ctrl + F`（Mac は `⌘ + F`）で変更したい文字（店名、電話番号など）を検索して上書きします。

各セクションの先頭には、次のような目印があります。

```html
<!-- ==================== Section: Menu ==================== -->
```

**使わないセクションがある場合は、** その目印から次のセクションの目印の手前までを削除し、ナビゲーションのリンクも削除してください。

### 必ず変更する項目（以下を検索してください）

| 検索する文字 | 置き換える内容 |
|---|---|
| サンプルの店名 | あなたの店名（「すべて置換」を使うと便利です） |
| サンプルの電話番号 | あなたの電話番号 |
| `wa.me/...` などのチャットリンク | 日本では **LINE 公式アカウント** のリンク（`https://lin.ee/xxxx` または `https://line.me/R/ti/p/@あなたのID`）に差し替えるのがおすすめです。Instagram の DM リンクでも構いません |
| `maps.google.com/?q=` のサンプル住所 | あなたの住所 |
| `your-form-id` | Formspree のフォーム ID（第 6 章を参照） |
| `<title>` と `description` | 店名と一行の紹介文（Google の検索結果に表示されます） |
| `application/ld+json` のブロック | 店名、電話番号、住所、営業時間（Google マップや検索結果に正しい情報を表示するのに役立ちます） |

> LINE 公式アカウントのリンクは、LINE Official Account Manager の「友だちを増やす」→「友だち追加ガイド」からコピーできます。

## 4. 色とフォントを変更する

`index.html` の上部に **THEME SETTINGS** があります。

```css
:root {
  --brand: #b5532c;   /* メインカラー：ボタンや強調部分 */
  --bg: #f7f1e8;      /* 背景色 */
  --text: #2a211c;    /* 文字色 */
  ...
}
```

この値を変えるだけで、サイト全体の色が変わります。配色に迷ったら [coolors.co](https://coolors.co/) を試してみてください。

> ヒント：文字と背景のコントラストは十分に確保しましょう。[WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) で確認できます。

## 5. 自分の写真を使う

画像エリアは、デザインされたグラデーションのイラストで作られているため、ストック写真のライセンスを気にする必要はありません。実際の写真を使う場合は次の手順で行います。

1. 写真を `index.html` と同じ階層の `images/` フォルダに入れます（例：`images/hero.jpg`）。
2. `index.html` で `Replace with a photo` を検索すると、次のようなコメントが見つかります。
   ```css
   /* Replace with a photo: .img-hero { background: url(images/hero.jpg) center/cover; } */
   ```
3. その行（コメント記号 `/*` `*/` は除く）を `</style>` の直前にコピーし、ファイル名を変更します。

**写真のコツ**
- 横幅 1600〜2000px あれば十分です。[Squoosh](https://squoosh.app/) で圧縮するとサイトの表示が速くなります。
- 使えるのは、ご自身で撮影した写真か、使用許可のある写真だけです（例：[Unsplash](https://unsplash.com/) や [Pexels](https://www.pexels.com/) の商用利用可能な画像）。

## 6. フォームの内容をメールで受け取る（Formspree・無料）

1. [formspree.io](https://formspree.io/) に登録し、**New Form** をクリックします。
2. フォームの URL の末尾にある ID（例：`xyzabcd`）をコピーします。
3. `index.html` で `your-form-id` を検索し、コピーした ID に置き換えます。

これで、送信された内容があなたのメールに届きます。日本からでも海外と同じように使え、日本語の入力もそのまま届きます。無料プランでは月 50 件まで受信できます。フォームが不要な場合は、フォームのセクションを削除し、電話や LINE のボタンだけを残しても構いません。

## 7. サイトを公開する（いずれも無料）

### A. Netlify Drop（いちばん簡単・約 3 分）
1. [app.netlify.com/drop](https://app.netlify.com/drop) を開きます。
2. フォルダ全体（全言語を公開）または言語フォルダ 1 つをページにドラッグします。
3. 完了です。`xxx.netlify.app` のアドレスが発行されます。無料アカウントを作るとサイトを保存し、名前を変更できます。

### B. GitHub Pages
1. GitHub のアカウントを作り、新しいリポジトリを作成します。
2. **Add file → Upload files** から `index.html` と `images/` フォルダをアップロードします。
3. **Settings → Pages** で `main` ブランチを選び、Save をクリックします。
4. 1〜2 分で `https://ユーザー名.github.io/リポジトリ名/` にサイトが公開されます。

### C. Cloudflare Pages
[pages.cloudflare.com](https://pages.cloudflare.com/) を開き、**Upload assets** を選んでフォルダをアップロードします。

### 独自ドメインを使う（例：`www.yourshop.jp`）
ドメインは、日本で利用者の多い [お名前.com](https://www.onamae.com/) や [ムームードメイン](https://muumuu-domain.com/)、または原価に近い価格で更新できる [Cloudflare](https://www.cloudflare.com/ja-jp/products/registrar/) などで取得できます。取得後、Netlify・GitHub・Cloudflare の「Custom domain（カスタムドメイン）」の手順に従って設定してください。

> `.jp` ドメインは日本国内に住所がある個人・法人のみ登録できます。`.com` などはどなたでも取得できます。

## 8. Google で見つけてもらう

1. [Google Search Console](https://search.google.com/search-console) にサイトを登録し、所有権を確認します。
2. [Google ビジネスプロフィール](https://business.google.com/)（旧 Google マイビジネス）を作成し、ウェブサイトの URL を登録します。地域密着のお店にとっては、これがもっとも効果的な対策です。営業時間・写真・口コミへの返信もここで管理できます。

## 9. プライバシーと EU からの訪問者（個人情報保護法・GDPR）

- **地図**：テンプレートは Google マップを埋め込まず、リンクで開く方式です。訪問者がクリックするまで Google からは何も読み込まれません。
- **フォント**：フォントは Google Fonts から読み込んでいます。EU 向けに厳密な GDPR 対応をしたい場合（特にドイツの事業者に推奨）は、フォントを自分のサーバーに置きます。
  1. [gwfh.mranftl.com/fonts](https://gwfh.mranftl.com/fonts)（google-webfonts-helper）を開き、`index.html` 上部の `fonts.googleapis.com` のリンクに書かれているフォントを選びます。
  2. `woff2` ファイルを `index.html` と同じ階層の `fonts/` フォルダにダウンロードし、生成された CSS を `<style>` ブロックにコピーします。
  3. `fonts.googleapis.com` と `fonts.gstatic.com` を指す `<link>` タグを削除します。
- **プライバシーポリシー**：日本の事業者は、個人情報保護法に基づき個人情報の利用目的を公表する必要があります。`プライバシーポリシー雛形.md` を編集して `privacy.html` として保存し、フッターからリンクしてください。ネットショップなど通信販売を行う場合は、別途 **特定商取引法に基づく表記** のページも必要です（ドイツ・オーストリアの事業者は **Impressum** ページが必要です）。
- **フォーム**：Formspree（米国の事業者）が送信内容を保存します。外国にある第三者への提供にあたるため、プライバシーポリシーに記載してください。

## 10. よくある質問

**スマートフォンでフォントの見た目が違います。**
テンプレートは Google Fonts をオンラインで読み込んでいます。通信が遅い場合、ブラウザは先にシステムフォントで表示します。これは正常な動作です。

**複数ページのサイトにできますか？**
できます。`index.html` を `about.html` などの名前でコピーし、不要なセクションを削除して、ナビゲーションのリンク先を `about.html` に変更してください。

**どこかを壊してしまいました。**
編集前に元のファイルのバックアップを取っておくか、購入したファイルを再ダウンロードしてください。
