# 使用說明

感謝購買！這份說明會帶你在 30 分鐘內把網站改成你的（或你客戶的）樣子並上線。完全不需要寫程式的經驗。

---

## 1. 檔案內容

```
index.html      ← 整個網站就是這一個檔案
images/         ← 放你自己的照片
使用說明.md     ← 這份文件
授權條款.md     ← 使用範圍
```

## 2. 需要的工具（都免費）

- 文字編輯器：推薦 [VS Code](https://code.visualstudio.com/)。Windows 內建的「記事本」也可以，只是比較難找到要改的地方。
- 瀏覽器：Chrome、Edge、Safari 都可以。

直接用瀏覽器打開 `index.html`，就能看到網站。改完存檔後，回到瀏覽器按重新整理就會看到新的樣子。

## 3. 修改文字

用編輯器打開 `index.html`，按 `Ctrl + F`（Mac 按 `⌘ + F`）搜尋你想改的文字，例如店名、電話，直接換掉就好。

每個區塊前面都有這樣的標記，可以用來找位置：

```html
<!-- ==================== 區塊：菜單 ==================== -->
```

**不需要某個區塊？** 從這行標記開始，刪到下一個區塊標記之前就可以了。記得也把導覽列裡對應的連結一起刪掉。

### 一定要改的地方（搜尋這些字）

| 搜尋 | 改成 |
|---|---|
| 範例店名 | 你的店名（出現好幾次，建議用「全部取代」） |
| `02-1234-5678` 或其他範例電話 | 你的電話 |
| `@yourlineid` | 你的 LINE 官方帳號 ID |
| `maps.google.com/?q=` 後面的地址 | 你的地址 |
| `your-form-id` | 你的 Formspree 表單 ID（見第 6 節） |
| `<title>` 和 `description` | 你的店名和一句介紹，這會顯示在 Google 搜尋結果裡 |
| `application/ld+json` 裡的資料 | 店名、電話、地址、營業時間（讓 Google 地圖和搜尋結果正確顯示你的店家資訊） |

## 4. 修改顏色與字型

打開 `index.html`，找到最上方的 **「主題設定」**：

```css
:root {
  --brand: #b5532c;   /* 主色：按鈕、重點文字 */
  --bg: #f7f1e8;      /* 背景色 */
  --text: #2a211c;    /* 文字顏色 */
  ...
}
```

只要改這裡的色碼，整個網站就會跟著換色。可以到 [coolors.co](https://coolors.co/) 挑配色。

> 小提醒：文字顏色和背景顏色要有足夠的對比，才看得清楚。可以用 [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) 檢查。

## 5. 換成真實照片

模板裡的圖片區塊目前是設計過的漸層圖案，換成你自己的照片很簡單：

1. 把照片放進 `images/` 資料夾，例如 `images/hero.jpg`。
2. 在 `index.html` 搜尋 `換成照片`，會找到像這樣的註解：
   ```css
   /* 換成照片：.img-hero { background: url(images/hero.jpg) center/cover; } */
   ```
3. 把註解裡的那一行複製到 `</style>` 的前一行，改成你的檔名就完成了。

**照片建議**
- 寬度 1600–2000px 就夠了。可以先用 [Squoosh](https://squoosh.app/) 壓縮，網站會快很多。
- 照片必須是你自己拍的，或是有合法授權的，例如 [Unsplash](https://unsplash.com/) 和 [Pexels](https://www.pexels.com/) 上可免費商用的圖片。

## 6. 讓表單收得到信（Formspree，免費）

1. 到 [formspree.io](https://formspree.io/) 註冊，按 **New Form**。
2. 複製表單網址最後面那串 ID，例如 `xyzabcd`。
3. 在 `index.html` 搜尋 `your-form-id`，換成你的 ID。

之後有人送出表單，你的 Email 就會收到通知。免費方案每月可以收 50 封。

不想用表單的話，也可以把表單區塊刪掉，只留電話和 LINE 按鈕。

## 7. 上線（三選一，都免費）

### A. Netlify Drop（最簡單，3 分鐘）
1. 打開 [app.netlify.com/drop](https://app.netlify.com/drop)。
2. 把整個資料夾（裡面有 `index.html` 和 `images/`）拖進網頁。
3. 完成！會得到一個 `xxx.netlify.app` 網址。註冊帳號後就能保留網站並修改網址。

### B. GitHub Pages
1. 註冊 GitHub，建立一個新的 repository。
2. 按 **Add file → Upload files**，上傳 `index.html` 和 `images/` 資料夾。
3. 到 **Settings → Pages**，Source 選 `main` 分支，按 Save。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/repository名稱/`。

### C. Cloudflare Pages
到 [pages.cloudflare.com](https://pages.cloudflare.com/)，選 **Upload assets**，上傳資料夾即可。

### 想用自己的網域（例如 `www.你的店.com`）？
先到網域商（例如 Cloudflare、Gandi、PChome 買網域）購買網域（一年約 NT$300–800），再到 Netlify、GitHub 或 Cloudflare 的「Custom domain」設定頁，照指示設定。

## 8. 讓 Google 找得到你

1. 到 [Google Search Console](https://search.google.com/search-console) 新增你的網站並驗證。
2. 申請 [Google 商家檔案](https://business.google.com/)，並在裡面填上你的網站網址。這是在地店家最有效的曝光方式。

## 9. 常見問題

**Q：手機上的字型和電腦上不一樣？**
模板使用 Google Fonts，需要網路才能載入；網路不穩時，會改用系統字型顯示，這是正常的。

**Q：可以改成多頁嗎？**
可以。把 `index.html` 複製一份，改名成 `about.html` 之類的檔名，刪掉不需要的區塊，再把導覽列的連結改成 `about.html` 就可以了。

**Q：改壞了怎麼辦？**
改之前先備份一份原始檔案。也可以重新下載你購買的檔案。
